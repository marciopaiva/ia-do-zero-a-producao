## Apêndice A — Glossário de termos técnicos

**Algoritmo**: Procedimento ou conjunto de regras para resolver um problema.

**API** (Application Programming Interface): Interface que permite comunicação entre sistemas.

**Fine-tuning**: Ajuste adicional de um modelo pré-treinado para uma tarefa específica.

**GPU** (Graphics Processing Unit): Hardware especializado para computação paralela, crucial para treinar redes neurais.

**Inferência**: Uso de um modelo treinado para fazer previsões sobre novos dados.

**LLM** (Large Language Model): Modelo de linguagem de grande porte, como GPT-4 ou Claude.

**Prompt**: Entrada fornecida a um modelo de IA.

**Token**: Unidade básica de texto processada por modelos de linguagem.

**Tokenização**: Processo de converter texto em tokens.

**Transformer**: Arquitetura de rede neural que revolucionou o processamento de linguagem.

## Apêndice C — Templates de prompts

### Para escrita criativa
```
Escreva um [texto tipo] sobre [tema] destinado a [público-alvo].
Tone: [formal/coloquial/inspirador]
Extensão: aproximadamente X palavras.
Inclua 3 pontos principais e uma conclusão.
```

### Para código
```
Escreva uma função em [linguagem] que faz [descrição da tarefa].
Considere casos de borda: [liste casos].
Siga as convenções de estilo de [estilo].
```

### Para análise
```
Analise o seguinte texto e extraia: [informações desejadas].
Formato de saída: [JSON/tabela/lista].
```
